# Make Cineora feel premium, rich, and polished

The audits confirm the foundation is genuinely strong — glass token hierarchy, skeleton mirroring, motion governance, error/empty-state craft are all at production quality. The gap is **temporal and dimensional polish**: things that *move*, things that *feel physical*, and the few a11y gaps a premium product must close.

I'm proposing 10 focused upgrades, ordered by visual impact, all doable as localized changes without a rewrite. Every one respects the existing design tokens and reduced-motion governance.

---

## 1. Cinematic detail-hero backdrop (highest impact)
**Files:** `src/components/detail/DetailHero.tsx:30-48`, `src/app/globals.css`

The home hero breathes via `animate-drift`; the detail hero (the most-important screen) is static. Wrap the backdrop `PosterImage` in a div with `animate-drift` — or add a subtler `animate-drift-slow` keyframe (40-60s) so the page feels alive without distracting from the title. Add a slow ambient halo glow layer behind the poster-inset. Respect `prefers-reduced-motion` (already does via the global rule).

## 2. Watch-stage entrance + ambient glow
**Files:** `src/components/player/NxshaPlayer.tsx`, `WatchScreen.tsx:327`

When the embed's `phase` transitions `loading → loaded`, fade the scrim out over ~600ms and add a subtle `scale-[0.985→1]` entrance to the stage (new `animate-player-in` keyframe). Add a soft vignette/glow ring behind the player stage so it reads as "a screen in a dark room," not a box on a page. Add a pulsing "NOW PLAYING" accent pill in the watch header.

## 3. Scroll-triggered entrance for rails & grids
**File:** `src/components/browse/BrowseGrid.tsx`, `src/components/media/MediaCard.tsx`, `globals.css`

Cards/rails currently pop in as a block. Add an `animate-stagger` utility (opacity + translate-y, with per-child `animation-delay` via `nth-child` or an inline style set by `MediaGrid`). Rails get a slide-in reveal. Netflix/Apple TV+ both do this — it makes a grid feel *loaded*, not *rendered*. Fully reduced-motion safe (duration collapses to 0.01ms).

## 4. Richer card-at-rest + featured tile
**Files:** `src/components/media/MediaCard.tsx`, `BrowseGrid.tsx`

Cards are flat at rest and only dimensional on hover. Add a faint resting shadow + a hairline ring so the grid has depth before interaction. Introduce a `featured` card variant (spans 2 cols, shows overview + backdrop behind the poster) for the first item in browse/search grids — the "editor's choice" tile that breaks uniform grids and signals curation.

## 5. Continue-watching progress bars
**Files:** `src/components/library/LibraryView.tsx`, `MediaCard.tsx`

Add a thin (2-3px) accent progress bar under in-progress thumbnails. Accept an optional `progress` prop on `MediaCard`. This single pattern — "you're 40% through" — is the strongest signal that the app *knows* you.

## 6. Player-bar richness + "Now Playing" header
**Files:** `src/components/player/PlayerBar.tsx`, `WatchScreen.tsx:304-323`

The control bar is glass-1 and visually quiet. Add an active-state glow ring + accent tint to the engaged control, a small poster thumbnail next to the title in the header, and a "S1 · E3" / "NOW PLAYING" accent pill. The sheets (Server/Audio/Subtitle) get a "Recommended" badge on the default option and a subtle selected-state glow.

## 7. Typography scale system
**File:** `src/app/globals.css`

Sizes are currently ad-hoc (`text-[1.0625rem]`, `text-[1.875rem]`, etc.). Add a small token scale: `--text-display`, `--text-heading`, `--text-subheading`, `--text-body`, `--text-caption` with balanced line-heights and tracking. Migrate the 6-8 most common heading sizes to use them. This makes the type feel *intentional* rather than assembled.

## 8. Account area → premium dashboard
**Files:** `src/components/account/AccountShell.tsx`, `AccountOverview.tsx`

The account section is a flat grid of identical glass-1 tiles — it reads as a settings form, not a premium dashboard. Add a glass-3 hero card at the top of Overview (member since, avatar, quick stats), use glass-2/3 level contrast between primary and secondary tiles, and replace the bare spinner with section skeletons.

## 9. Micro-interaction polish (press feedback + hover variety)
**Files:** `globals.css`, `MediaCard.tsx`, `PlayerBar.tsx`

Beyond the uniform `.tap:active { scale(0.97) }`: add a subtle press glow on buttons, a brightness/hue shift on glass hover (not just `bg-white/6`), and an icon-morph on the play button. Add a `pressed` state class for touch feedback that doesn't rely on hover.

## 10. Accessibility gaps (premium = inclusive)
**Files:** `SearchOverlay.tsx:227`, `Sheet.tsx`, `Toast.tsx:72`, `Rail.tsx:106`, `globals.css`

Fix the 5 concrete a11y gaps the audit found:
- Search input `outline-none` with no replacement ring → add `focus-visible:ring-2 focus-visible:ring-ruby-400/70`.
- No `inert` on page content behind modals → set `inert` + `aria-hidden` on main content when Sheet/SearchOverlay is open.
- Toast dismiss button has no accessible name → add `aria-label="Dismiss"`.
- Horizontal rails not keyboard-scrollable → make `RailArrow` focusable with a label.
- `forced-colors` (Windows High Contrast) handling → add `@media (forced-colors: active)` block reinforcing borders with `CanvasText`.

---

## What I will NOT change
- The glass token architecture — it's excellent and I'll build on it.
- The motion governance — every new animation respects reduced-motion.
- The Nxsha player's lack of transport controls — that's an honest boundary (cross-origin iframe, no control API), not a polish gap.
- The download system's operator-catalogue model — that's a rights boundary, not a UI one.

## Verification
After implementation: `npx tsc --noEmit` + `npm run build` must pass, then I'll drive the app in the In-app Browser across the 7 required viewports (390×844, 412×915, 768×1024, 1280×720, 1440×900, 1920×1080, plus WebView fullscreen) to confirm no horizontal overflow, no contrast regressions, and that animations collapse under reduced-motion.
